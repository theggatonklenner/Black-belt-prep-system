# Black Belt Preparation Management System

A mobile-friendly system for managing Taekwondo black belt preparation cycles: attendance, readiness, payments, grading, certificates and ID card printing.

## Core principle

Attendance, readiness, payment, grading eligibility, grading result, certificate status and ID card status are tracked separately. No status is ever set automatically from another; an authorised person makes the final call.

## Data and privacy

This project handles student and payment records. Keep the repository private, never commit real student data, and do not store card numbers or banking credentials.
